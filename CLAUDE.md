# vienna_planning_toolkit: project instructions

Global rules: `~/.claude/CLAUDE.md`. This file only adds project specifics.

| Field | Value |
|-------|-------|
| Environment | dev |
| Visibility | intended public: generic tools only |
| Targets pipeline | `_targets.R` (preset -> DXF -> validation -> plan file -> editor page, Elektro DXF; DXF tools on the sample) |
| Languages | Python (ezdxf, shapely) for drawing tools and the page build; plain JS/CSS for the editor page; R `targets` for orchestration |

## Purpose

Generic, data-free tools for Vienna-style building plans: DXF layer handling
and an electrical installation-plan editor (one page: GitHub
Pages `site/index.html`). The repo contains NO real
building data, ever: no real addresses, owners, plans, layer lists or
dimensions taken from a real project. The only sample drawing,
`samples/synthetic_flat.dxf`, is synthetic and generated by code.

Real project files belong in a separate private location and must never be
copied, quoted or used as test fixtures here.

## Commands (from any cwd, absolute paths)

```bash
P=/path/to/vienna_planning_toolkit
nix-shell $P/default.nix --run "python3 $P/tools/synthetic_flat.py"
nix-shell $P/default.nix --run "python3 -m pytest $P/tests -q -p no:cacheprovider"
nix-shell $P/default.nix --run "R_PROFILE_USER=/dev/null Rscript -e 'setwd(\"$P\"); targets::tar_make()'"
nix-build $P/nix/vpt.nix                                                              # the package
nix-shell $P/nix/vpt-shell.nix --run "python3 $P/tools/check_installed.py $P"         # installed, from outside the repo
```

A new data folder or file type the package reads at run time must be added to pyproject.toml (`package-dir`,
`package-data`); tests/test_package.py fails when a needed file would not ship.

`R_PROFILE_USER=/dev/null` stops a personal `~/.Rprofile` from loading
packages the project shell does not have.

Regenerate `default.nix` (cwd-safe subshell form):

```bash
(cd $P && nix-shell ~/docs_gh/llm/default.nix --run "Rscript default.R")
```

## Conventions

- Layer names: `<storey>_<nn>_[Abbruch_|Neubau_]<base>`, ASCII only, built from
  `presets/*.json` (`layer_name_regex` is checked by the validator).
- Every number or text in a generated drawing comes from the preset. If you
  need a new dimension, add it to the preset, not to the generator.
- The generated DXF must stay byte-identical for an unchanged preset; header
  timestamps and GUIDs come from the preset.
- Every new validator check gets a falsification test (a broken drawing it
  must reject).
- The page must stay a whole, self-contained HTML document (no external
  resources, theme tokens present); `tools/build_editor.py` gates it. Texts in a generated SVG
  are `<text>` elements, never glyph outlines (those depend on system fonts).
