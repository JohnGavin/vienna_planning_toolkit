The editor

The electrical editor

One tab per storey of the plan. Drag symbols from the palette onto the drawing (or click a symbol, then click the drawing). While you place a symbol, faint rings show where the placement rules suggest it (switches beside the doors, sockets in the middle of the walls, ceiling lights in the room centre, kitchen outlets along a kitchen's walls); let go near one and the symbol snaps onto it. Move, rotate, delete and undo as needed. Connect: click a switch, then the lights it works; the page groups the lights and proposes the switch type (Ausschaltung, Wechselschaltung, Kreuzschaltung), which Apply puts in. Layout hints list lights without a switch, switches without a light and doors without a switch. Keep your work as a layout file (Save or Copy layout); Open layout brings it back.

1. Open your own plan

  1. On your computer, run python3 tools/export_plan.py your.dxf: it writes your.plan.json next to it.
  2. Click Open plan… and pick that file (or paste its text): it is read in this browser only.
  3. Each storey gets a tab; tick the drawing layers you want under the symbols.

Details: Open plan · Paste a file · Plan file format · Privacy: your drawing stays on your computer

2. Place symbols

  1. Drag a symbol from the Symbols palette onto the drawing and let go where it belongs, or click it in the palette and then click the drawing.
  2. Its insertion point lands exactly where you let go; zoom and pan never move it.
  3. Escape cancels a symbol picked in the palette.

Details: Symbol palette · Placing a symbol · Symbol set · UNVERIFIED symbols

3. Move, rotate, delete, undo

  1. Click a placed symbol to select it (dashed box); drag it to move it.
  2. Rotate 90° (key R) turns it; a socket's stem points to its wall.
  3. Delete (or the Delete key) removes the symbol or the selected link; Undo / Redo (Ctrl/⌘ + Z) take any change back.

Details: Select and move · Rotate 90° · Delete · Undo / Redo

4. Connect switches to lights

  1. Click Connect: the switches are marked; everything else is dimmed.
  2. Click a switch: the symbols it may control are marked green; the rest stay dimmed.
  3. Click each light it works: a dashed line (Wirkungslinie) is drawn on the layer Elektro – Verbindungen.
  4. Escape or Connect again stops.

5. Switch type: proposal and Apply

  1. Under the drawing, Switching groups lists each set of lights that share switches.
  2. The page proposes the switch type from the number of switches: 1 Ausschaltung, 2 Wechselschaltung, 3 or more Kreuzschaltung.
  3. Apply swaps the placed switch symbols to the proposal; nothing changes without it.

The same code builds two pages (tools/build_editor.py). The GitHub Pages version is for real work: Save layout, Save to file (Chrome, Edge), Save parameters and Print view. The shareable demo (a claude.ai artifact) cannot download, save or print: there you Copy the layout or the parameters, and the draft stays in the browser. Both open a plan, layout or parameter file from your computer, or accept its text by paste.

Privacy: your drawing stays on your computer

The page is one self-contained file: no server, no analytics, nothing loaded from other sites. A plan, layout or parameter file you open or paste is read by this browser only. Drafts stay in this browser's storage. tools/export_plan.py runs on your own computer and writes the plan file there; the plan file holds the DXF's file name and checksum, not its folder.

Open plan

Opens a plan file (<name>.plan.json) that tools/export_plan.py wrote from your DXF. It is read in this browser and never uploaded. It is checked first, with three outcomes: a valid plan file (opened: the storeys replace the sample); another kind of file, e.g. a layout or parameter file (refused, saying what it is); or it could not be told (not JSON, not a valid plan file, a drawing that does not parse: refused, with the reason). You can also paste the file's text anywhere on the page.

Paste a file

Paste (⌘V / Ctrl+V) the text of a plan file, a layout file or a parameter file anywhere on the page outside an input box: the page sees which kind it is and opens it as if you had opened the file, with the same checks and the same three outcomes. Text that is not one of these is refused with the reason.

Storeys

Each storey of the plan has its own tab, its own symbols and its own draft. The sample flat has one storey.

Drawing layers

The plan's drawing layers of this storey, grouped by base name, with toggles per status (Bestand, Abbruch, Neubau), per base name and per layer. On screen the drawing is shown light on a black stage (each CAD colour keeps its hue, so Bestand, Abbruch and Neubau stay apart); the print is dark on white paper. Which layers are shown is saved in the layout file and applied again when it is opened.

Electrical layers

Placed symbols live in their own layers, one per category (Elektro – Licht, Elektro – Schalter, ...); the links (Wirkungslinien) have their own layer, Elektro – Verbindungen. Tick or untick a layer to show or hide it on screen and in the print; the numbers are the symbols (or links) on each layer.

UNVERIFIED symbols

These symbols were drawn for this toolkit from general knowledge of the IEC 60617 conventions for installation plans (ÖVE/ÖNORM EN 60617; installation standard OVE E 8101). They have NOT been checked against the standard text or an Elektroplaner's legend, so a symbol may differ from the official one. Use them to plan where things go; ask the Elektroplaner to confirm the symbols before the plan is used for the installation.

Symbol palette

The symbols of the chosen set, grouped by category (Licht, Schalter, Steckdosen, Küche/Geräte, Daten/TV, Sicherheit, Verteiler), each with its German and English name. Drag one onto the drawing (mouse or finger), or click it (it stays selected, marked) and then click the drawing; Escape cancels. The palette folds away with its title.

Placing a symbol

Drag a symbol from the palette and let go over the drawing: its insertion point lands where you let go. Or click the symbol in the palette, then click the drawing (with the keyboard: Enter on the symbol, then Enter on the drawing places it in the middle of the view). The position is stored in drawing (model) coordinates, so zoom and pan do not move it, and it is the same position a DXF export will use.

Select and move

Click a placed symbol to select it (dashed box); drag it to move it. Click the empty drawing to deselect. Dragging the empty drawing pans the view.

Rotate 90°

Turns the selected symbol by 90 degrees counter-clockwise about its insertion point (key R). A socket's stem points to the wall it sits on: rotate until it does.

Delete

Deletes the selected symbol, with its links, or the selected link (keys Delete or Backspace). Undo brings it back.

Undo / Redo

Undo takes back the last change to the symbols and links (place, move, rotate, delete, connect, apply a proposal, open); Redo does it again (Ctrl/⌘ + Z, Ctrl/⌘ + Shift + Z). The history is kept until the page is closed.

Room of a symbol

Each placed symbol is given the id of the room it stands in, from the plan file's rooms: inside a room's outline; else the nearest label of a room that has no outline, when it is close enough (room_label_max_m in the parameters); else could-not-tell. The room is shown when the symbol is selected and saved in the layout file.

room_label_max_m = 2 m: A symbol outside every room outline is given the nearest room label of a room WITHOUT an outline when that label is at most this far away (method 'nearest label'); else its room is could-not-tell. Starting value - confirm.

symbol_scale = 1: Placed symbols are drawn at their nominal size in mm on the storey sheet (presets/el_symbols_at.json) times this factor. Starting value - confirm.

Connect (switch to light)

Turns Connect mode on or off. In Connect mode the switches and push-buttons are marked and everything else is dimmed. Click a switch: the symbols it may control (its 'may be connected to' list in the symbol set) are marked green and the rest stay dimmed. Then click each light it works: every click adds a link, drawn as a dashed line (Wirkungslinie) on the layer Elektro – Verbindungen. A click on a symbol the switch may not control is refused and the message names what it may control. Click another switch to start from it, the same switch again or Escape to stop. Symbols do not move in Connect mode.

Links (Elektro – Verbindungen)

The links between switches and lights, as dashed lines between the symbols' insertion points, on their own layer: tick it off to hide them on screen and in the print. Click a line to select it (it gets thicker); Delete removes it, Undo brings it back. Deleting a symbol deletes its links too.

A dashed line from a switch or push-button to each light it works, on its own layer. Drawn between the symbols' insertion points (straight lines, not cable routes). Colour and width: presets/el_parameters.json.

Switching groups and the proposed switch type

A group is a set of lights that share switches (joined by links). For each group the page proposes the switch type from the number of switches: one: Ausschaltung (one-way switch); two: Wechselschaltung (two two-way switches); three or more: Kreuzschaltung (two two-way switches and an intermediate switch for every further place). A group with a push-button gets no proposal (Tasterschaltung: the Elektroplaner decides). The proposal is only shown; nothing changes until you click Apply.

A light group is a set of lights that share switches (switches and lights joined by links). The page PROPOSES the switch type from the number of switches in the group: one switch: Ausschaltung (one one-way switch); two: Wechselschaltung (two two-way switches); three or more: Kreuzschaltung (two two-way switches and an intermediate switch for every further place). Apply swaps the placed switch symbols to the proposed codes; nothing changes without it. A group with a push-button gets no proposal: push-buttons work an impulse relay or a timer, whatever their number (the Elektroplaner decides). This is the textbook wiring rule; how the group is actually wired is for the Elektroplaner.

Apply the proposal

Swaps the placed switch symbols of this group to the proposed codes (e.g. two one-way switches become two two-way switches); positions, rooms and links stay. One click, one Undo step.

The choice is saved in the layout file.

Snap to suggestions

When on (the default), a symbol let go near a suggestion of its kind (within the snap radius, snap_radius_m in the parameters) is placed exactly on it and turned to its wall. Switch it off, or hold Alt/Option while letting go, to place a symbol exactly where you let go.

Suggestions (show all)

Shows every placement suggestion of the chosen rule set on this storey, coloured like the symbols it is for. Untick to hide. While you place a symbol only its own kind is shown.

Placement suggestions (faint rings)

While a symbol is being placed (dragged from the palette, picked in the palette, or moved), rings show where the chosen rule set suggests that kind of symbol on this storey; those of the room under the pointer are brighter and the one it would snap to is yellow. The rings keep their size on screen at every zoom. Tick Suggestions in the bar to see every suggestion at any time, coloured by symbol category. Hover a ring for its rule. Switches: beside each door of a room, on the room's side, on the handle side (opposite the hinge, from the door swing in the plan). Sockets: the middle of each wall piece between the doors of a room. Ceiling lights: the room centre. Kitchen and appliance outlets: along the walls of rooms whose label marks a kitchen. A room without an outline has no walls here (no socket or kitchen suggestion), a door whose swing could not be determined has no switch suggestion; the status line says how many. Windows are not known to the plan: a suggestion may fall in a window niche. Wall lights and the other symbols have no rule.

  • Switch beside a door: symbols SA, SW, SK, ST; values switch_from_frame_m, switch_inset_m, switch_inset_other_m.
  • Socket at the centre of a wall piece: symbols SO, SS1, SS2; values socket_min_piece_m, socket_inset_m, door_cut_max_m.
  • Ceiling light at the room centre: symbols LD; values ceiling_light_at.
  • Kitchen outlets along the walls of a kitchen: symbols HE, GS, BO, KS, WM; values kitchen_keywords, kitchen_spacing_m, kitchen_end_margin_m, socket_inset_m, door_cut_max_m.

Examples (simple, complex)

When you have no layout of your own on a storey, the storey chosen by the example rule opens with the SIMPLE example: one room with a ceiling light at the room centre, a two-way switch at each of its two doors (Wechselschaltung), both linked to the light, and two sockets in the middle of walls. Switch the selector to COMPLEX for the whole storey: a light, a smoke alarm and a switch at every door of each room (switch type as proposed), sockets on every wall piece, kitchen outlets in kitchens and one distribution board. Both are generated by vpt/el_examples.py from the rooms and doors of the plan and the placement suggestions (nothing is placed by hand); the symbols they use are parameters. An example is marked EXAMPLE and is never kept as a draft. As soon as you change anything it becomes your own layout (kept as a draft). Switching to another example when you have your own symbols asks first; Undo brings them back. The rule for the example's storey and room:

the first storey (in plan order) with a room (in id order) that has an outline, a ceiling-light suggestion, exactly examples.simple_doors doors with a switch suggestion on the room's side, and at least examples.simple_sockets wall-centre socket suggestions.

Clear example

Removes the example from this storey (symbols and links), so you start from an empty storey. Your own layouts are never touched by it.

Copy parameters

Copies the parameters (the same JSON text Save parameters writes) to the clipboard; when the browser does not allow it, the text is shown in a box, selected, to copy by hand.

Save parameters

Downloads the parameters as el_parameters.json (with the time and page it was saved from). To use them for the suggestions, put the file at presets/el_parameters.json and export the plan again. Save to file… (Chrome, Edge) writes back into a file you chose. Only in the GitHub Pages version.

Load parameters

Opens a parameter file (or paste its text) after checking it against schema/el_parameters.schema.json and the page's rules: loaded (valid, same parameters); refused as different (another page's parameters, or other sections or rules); refused as could not tell (not JSON, not a valid parameter file, or values that break the rules, e.g. a colour with less than 3:1 contrast against its background).

Reset parameters

Throws away your edits and loaded values and goes back to the parameters the page was built with.

Layout hints

A short list per storey, updated with every change, each with three outcomes (ok, to look at, could not tell). They are hints for the plan, not a check of the installation.

H1 Lights with no switch

Every light that no link reaches. Could not tell when no light is placed (nothing to check).

H2 Switches with no light

Every switch or push-button without a link. Could not tell when no switch is placed.

H3 Doors without a switch

For every room with a light: each door of the room must have a switch or push-button within the rule's distance of its opening (hint_switch_near_door_m). Could not tell: no value yet in the chosen rule set, a light whose room could not be told, a room with no door known, or a plan without rooms and doors.

Save layout

Downloads the layout of this storey as a file <drawing>__<storey>.electrical.json (into your Downloads folder, or where the browser asks). It holds the drawing's checksum and storey, the symbol set, the shown drawing layers and every symbol with its drawing coordinates, rotation and room, and the links. Nothing leaves your computer.

Save to file (Chrome)

Shown only in browsers that can write to a file you chose (Chrome, Edge): the first click asks where to save; after that, or after Open layout in such a browser, each click saves back into the same file in place.

Copy layout

Copies the layout of this storey (the same JSON text Save layout writes) to the clipboard, so you can paste it into a file, a message or another copy of this page. When the browser does not allow the clipboard, the text is shown in a box, selected, to copy by hand.

Open layout

Opens a layout file saved or copied before (or paste its text). It is checked first, with three outcomes: it belongs to this drawing and storey (opened); it belongs to another drawing or another storey (refused, with the reason); or it could not be told (not a layout file, a damaged file, an unknown symbol set, code or rule set, or a link the symbols do not allow: refused, with the reason). Opening replaces the symbols on this tab; you are asked first when there are some, and Undo brings them back.

Draft in this browser

Every change is also kept as a draft in this browser (when it allows it; a private window may not), so closing the page by mistake loses nothing: the draft comes back when the page is opened again. The draft is not a file: save or copy the layout to keep it. Discard draft clears the tab and the draft.

Controls

Zoom in (+)

Zooms in on the centre of the drawing. To zoom around the pointer instead: pinch on a trackpad, or hold Ctrl (⌘ on a Mac) and turn the mouse wheel.

Zoom out (−)

Zooms out from the centre of the drawing. To zoom around the pointer instead: pinch on a trackpad, or hold Ctrl (⌘ on a Mac) and turn the mouse wheel.

Pan (drag) and zoom (pinch, Ctrl/⌘ + wheel)

Drag the empty drawing with the mouse (or a finger) to move it. Pinch, or Ctrl (⌘ on a Mac) + mouse wheel, zooms around the pointer. The plain mouse wheel scrolls the page, not the drawing. The view stays on the storey: it cannot be zoomed out to nothing or dragged off the page (Reset view brings back the whole storey). Zoom and pan change only the view, never the drawing or a symbol's position.

Reset view

Shows the whole storey again. Layer ticks are not changed.

All layers on

Ticks every drawing layer of this storey, including those that are off in the DXF.

All layers off

Unticks every drawing layer, so you can then tick only the layers you want under the symbols.

Filter layers

Type part of a layer or base name to shorten the layer list. It only filters the list; it does not show or hide layers in the drawing.

Layers panel (fold)

Click the panel title to fold the layer panel away. The browser remembers your choice when it can (it still works when it cannot).

Print view

Switches to a print layout of this storey on one A3 landscape page: the drawing with the layers you ticked (dark on white), the electrical layers that are on, a title row, a scale note and a legend of the symbols placed. Leave it with Exit print view.

Fit storey / Current view

In the print view: Fit storey prints the whole storey; Current view prints the window you zoomed and panned to before opening the print view.

Exit print view

Returns to the editor with your layers, zoom and pan as they were.

How to print to PDF

Print view on a storey's tab prints the drawing layers and the electrical layers that are ticked, on one A3 landscape page with a title row, a scale note and a legend of the symbols actually placed (German names), with the note that the symbols are unverified. Then ⌘P / Ctrl+P, Save as PDF. Not available in this demo: use the GitHub Pages version.

  1. Tick the drawing layers and electrical layers you want on paper.
  2. Zoom and pan to the part you want, if you want only a part.
  3. Click Print view. Choose Fit storey (the whole storey) or Current view (the window you zoomed to).
  4. Press ⌘P (Mac) or Ctrl+P (Windows), or click Print / Save as PDF.
  5. Destination: Save as PDF. Paper size: A3. Layout: landscape. Margins: none. Background graphics: on.
  6. Click Save. Then click Exit print view to return to the editor.

The print view fills one A3 landscape page (420 x 297 mm, margins 8 mm): a title row, the drawing (404 x 255 mm), and a legend.

The scale note gives the printed scale on A3: the plan's page scale (1:100 for the sample) changed by fitting the storey or your current view to the A3 sheet.

Tested in Google Chrome. Safari and Firefox should work the same; check the preview before saving.
